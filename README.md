# 💰 Gestor de Gastos

Una aplicación sencilla y eficiente para el control de finanzas personales, seguimiento de ingresos, egresos y visualización de presupuestos.

---

## 🎯 Características Principales

* **Registro de Transacciones:** Control detallado de ingresos y egresos de dinero.
* **Categorización Inteligente:** Clasificación de gastos por etiquetas (Comida, Transporte, Servicios).
* **Reportes Visuales:** Gráficos intuitivos del estado de tus presupuestos.
* **Persistencia de Datos:** Arquitectura robusta con base de datos relacional.
